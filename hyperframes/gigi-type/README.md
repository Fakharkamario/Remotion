# Gigi kinetic type

A 9.2 s, 30 fps, 1920×1080 kinetic-type piece in the Gigi launch look (Inter, white and light grey, brand blue, black). The type motion copies the reference edit on its own frames. Each word pops in highlighted, a touch big and soft, and settles while the line re-centres. Words drop off from the left. Two cursors drag boxed words into a sentence. The backgrounds wipe and cut on the reference's frames. It ends with Aizal's profile card flipping up.
